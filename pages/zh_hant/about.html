01 // 個人簡介

歡迎來到我的數位工作空間。我是美國科羅拉多大學博爾德分校（CU Boulder）電機電腦工程系（ECE）的博士生，專注於數據驅動之安全性關鍵控制（Data-Driven Safety-Critical Control）與統計系統識別（Statistical System Identification）。我的博士研究核心為直接從經驗軌跡數據中合成控制屏障函數（CBFs）與最佳化安全過濾器，為不確定動態系統提供嚴謹的形式化安全保證，並結合最佳控制理論與閉迴路物理系統模擬進行驗證。

02 // 專業技術與研究焦點

MODULE 01 // SYSTEM ID 統計系統識別

直接從經驗輸入輸出軌跡數據中建立系統狀態空間數學模型，並推導嚴謹的不確定性邊界。

MODULE 02 // SAFETY CONTROL 安全過濾器與 CBF 合成

設計數據驅動控制屏障函數（CBFs）與最佳化安全過濾器，在不確定動態環境下確保系統滿足安全不變性。

MODULE 03 // OPTIMIZATION 最佳控制與強健合成

建構受約束之回授控制器與凸最佳化架構，在模型不確定性下同時兼顧系統安全與標稱控制效能。

MODULE 04 // SIMULATION 控制理論與動態模擬

開發強健的閉迴路回授控制系統，並使用 MATLAB Simulink 與 Simscape 進行多領域實體物理系統驗證。

TECHNICAL_APPROACH.LOG // 核心方法論
「數據提供模型，但分析結構提供安全保證。」

真實世界的物理系統極少符合教科書的理想假設——量測數據帶有雜訊，實際動態亦常包含未建模的不確定性或外部干擾。我的研究方法致力於結合統計學習與嚴謹的控制理論：從有限數據刻畫不確定性邊界、構建數據驅動控制屏障函數（CBFs），並在實際部署前透過模擬對控制器進行極端情境的壓力測試。
