01 // 个人简介

欢迎来到我的数字工作空间。我是美国科罗拉多大学博尔德分校（CU Boulder）电气计算机工程系（ECE）的博士生，专注于数据驱动之安全性关键控制（Data-Driven Safety-Critical Control）与统计系统识别（Statistical System Identification）。我的博士研究核心为直接从经验轨迹数据中合成控制屏障函数（CBFs）与优化安全过滤器，为不确定动态系统提供严谨的形式化安全保证，并结合最优控制理论与闭环物理系统仿真进行验证。

02 // 专业技术与研究焦点

MODULE 01 // SYSTEM ID 统计系统识别

直接从经验输入输出轨迹数据中建立系统状态空间数学模型，并推导严谨的不确定性边界。

MODULE 02 // SAFETY CONTROL 安全过滤器与 CBF 合成

设计数据驱动控制屏障函数（CBFs）与优化安全过滤器，在不确定动态环境下确保系统满足安全不变性。

MODULE 03 // OPTIMIZATION 最优控制与强健合成

构建受约束的反馈控制器与凸优化架构，在模型不确定性下同时兼顾系统安全与标称控制性能。

MODULE 04 // SIMULATION 控制理论与动态仿真

开发强健的闭环反馈控制系统，并使用 MATLAB Simulink 与 Simscape 进行多领域物理系统验证。

TECHNICAL_APPROACH.LOG // 核心方法论
“数据提供模型，但分析结构提供安全保证。”

真实世界的物理系统极少符合教科书的理想假设——测量数据带有噪声，实际动态亦常包含未建模的不确定性或外部干扰。我的研究方法致力于结合统计学习与严谨的控制理论：从有限数据刻画不确定性边界、构建数据驱动控制屏障函数（CBFs），并在实际部署前通过仿真对控制器进行极端情景的压力测试。
